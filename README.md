# Creative Code — Visual Experiments

A collection of browser-based animations, visual studies, and explainers by Alejandro Mendoza / bobo labs. The work explores how code, motion, and visual storytelling can make ideas tangible.

## Working with the sketches

The collection uses JavaScript, p5.js, HTML, and CSS. Individual pieces may load libraries or assets from external sources.

To run the `bobo content` workspace with its local development server:

```bash
cd "bobo content"
npm install
npm start
```

For other folders, serve the relevant HTML file with a local static web server so asset paths resolve correctly.
